# Security and responsible use
OMNIEARTH+ publicly ships a static demonstration, with fictional event data and **no real live feeds**. Never commit API tokens, real fleet telemetry, client data, payment secrets, property owner contact details, photos with identifiable faces/plates, or raw dashcam video.

Please disclose vulnerabilities privately to the maintainer through GitHub private security reporting when enabled; otherwise contact maintainers without posting exploit data in public issues. Do not use public bug reports for confidential information.

Future production feeds need authentication, server-side authorization, redaction, purpose limitation, retention, revocation, audit logs and a privacy/legal assessment. No hidden employee tracking or exposing individually identifiable road-enforcement patrol locations. Respect all third-party map/data licenses and attribution.
