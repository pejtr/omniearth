# Optional privacy-preserving onion mirror (not deployed)
A **Tor onion service** is a website reachable through the Tor network via a private .onion address. This is legitimate technology for privacy and secure information access. It does **not** grant permission to misuse personal data, republish proprietary feeds, or conduct covert fleet/police monitoring.

OMNIEARTH+ currently has **no onion address and no dark-web integration**. A future onion mirror should expose only public OSS documentation or an authenticated, privacy-reviewed disclosure channel, not customer CRM, premium KATASTR reports or GPS traces.

If actually needed, use the official [Tor Project onion-service setup](https://community.torproject.org/onion-services/setup/). Host behind a separate hardened instance, keep onion private keys out of GitHub, restrict internal services, test information leaks and provide normal HTTPS access too.

No onion mirror will be provisioned until a concrete, privacy-positive user need exists.
