# Contributing to OMNIEARTH+
We welcome accessible mapping, accessibility, routing links, source provenance, privacy engineering and data visualizations.

Open an issue with steps, OS/browser and expected behavior. Do not attach personal GPS trails, customer records, photos of bystanders or proprietary tiles/videos. For security bugs, follow SECURITY.md.

Contributions must use original MIT-compatible source or prove licensing for code/assets/data. Mark simulated content **DEMO**; do not fake live map observations. Premium KATASTR-ONLINE.cz code stays in its private repository.
